================================================================================
案件管理システム セットアップ手順書
================================================================================

このシステムを初めて使う方向けのセットアップ手順です。
以下の手順に従って環境構築を行ってください。


================================================================================
■ 前提条件
================================================================================

以下のソフトウェアがインストールされている必要があります：

1. Node.js (バージョン 18以上推奨)
   - https://nodejs.org/ からダウンロードしてインストール
   - インストール確認: ターミナルで `node -v` を実行

2. Git
   - https://git-scm.com/ からダウンロードしてインストール
   - インストール確認: ターミナルで `git --version` を実行


================================================================================
■ セットアップ手順
================================================================================

【1. プロジェクトのクローン】

ターミナル（Windowsの場合はコマンドプロンプト）を開いて、以下のコマンドを実行：

```
git clone https://github.com/itsukih/project-manager.git
cd project-manager
```

※ GitHubアカウントでログインが必要な場合があります


【2. 依存パッケージのインストール】

プロジェクトフォルダに移動した状態で、以下のコマンドを実行：

```
npm install
```

※ 数分かかる場合があります


【3. 環境変数ファイルの作成】

プロジェクトフォルダ内に `.env` ファイルを作成し、以下の内容を記述：

```
DATABASE_URL="file:./dev.db"
```

【作成方法】
- Windowsの場合: メモ帳などで新規ファイルを作成し、「.env」という名前で保存
- Macの場合: テキストエディタで新規ファイルを作成し、「.env」という名前で保存


【4. データベースの初期化】

以下のコマンドを順番に実行：

```
npx prisma generate
npx prisma db push
```

これにより、空のデータベースが作成されます。


【5. 開発サーバーの起動】

以下のコマンドを実行：

```
npm run dev
```

成功すると、以下のようなメッセージが表示されます：

```
▲ Next.js 15.5.4 (Turbopack)
- Local:        http://localhost:3000
```


【6. ブラウザでアクセス】

ブラウザを開いて、以下のURLにアクセス：

```
http://localhost:3000
```

案件管理システムのトップページが表示されれば成功です！


================================================================================
■ 初期データの登録（推奨）
================================================================================

システムが起動したら、以下の順番でデータを登録することをおすすめします：

1. クライアント管理
   - まず取引先のクライアント情報を登録

2. 外注パートナー管理
   - デザイナーやコーダーなどの協力者を登録

3. テンプレート管理
   - よく使うスプレッドシートやPDFを登録

4. 案件一覧
   - 実際の案件を登録し、クライアントや外注パートナーを紐付け

5. タスク管理
   - 日々のタスクを登録


================================================================================
■ ポート番号を変更したい場合
================================================================================

デフォルトではポート3000で起動しますが、変更したい場合：

【Macの場合】
```
PORT=3011 npm run dev
```

【Windowsの場合】
package.json の "scripts" セクションを以下のように編集：

```
"scripts": {
  "dev": "set PORT=3011 && next dev --turbopack",
  ...
}
```


================================================================================
■ トラブルシューティング
================================================================================

【問題1】`npm install` でエラーが出る

対処法：
1. Node.jsのバージョンを確認（`node -v`）
2. バージョンが18未満の場合は、最新版をインストール
3. 再度 `npm install` を実行


【問題2】データベースエラーが出る

対処法：
1. `prisma/dev.db` ファイルを削除
2. 再度以下を実行：
   ```
   npx prisma generate
   npx prisma db push
   ```


【問題3】ポート3000が既に使われている

対処法：
1. 別のアプリケーションでポート3000を使用している可能性
2. 上記「ポート番号を変更したい場合」を参照


【問題4】ブラウザで表示されない

対処法：
1. ターミナルでエラーメッセージを確認
2. 開発サーバーが起動しているか確認
3. URLが `http://localhost:3000` になっているか確認
4. ブラウザのキャッシュをクリア


【問題5】画面が真っ白

対処法：
1. ブラウザの開発者ツール（F12キー）でエラーを確認
2. 開発サーバーを再起動（Ctrl+C で停止 → `npm run dev` で再起動）


================================================================================
■ システムの停止方法
================================================================================

開発サーバーを停止するには：

1. ターミナル上で `Ctrl + C` を押す
2. 「終了しますか？」と聞かれたら `Y` を入力してEnter


================================================================================
■ 再起動方法
================================================================================

システムを再度起動する場合：

1. プロジェクトフォルダに移動
   ```
   cd project-manager
   ```

2. 開発サーバーを起動
   ```
   npm run dev
   ```

3. ブラウザで `http://localhost:3000` にアクセス


================================================================================
■ データのバックアップ
================================================================================

データベースファイルは `prisma/dev.db` に保存されています。
定期的にこのファイルをコピーしてバックアップを取ることをおすすめします。

【バックアップ方法】
1. `prisma/dev.db` ファイルをコピー
2. 別の場所に保存（例: `backup/dev.db.20250122` など日付付きで保存）


【復元方法】
1. システムを停止
2. バックアップファイルを `prisma/dev.db` として上書き
3. システムを再起動


================================================================================
■ アップデート方法
================================================================================

システムが更新された場合の手順：

1. システムを停止（Ctrl+C）

2. 最新版を取得
   ```
   git pull origin develop
   ```

3. 依存パッケージを更新
   ```
   npm install
   ```

4. データベースを更新
   ```
   npx prisma generate
   npx prisma db push
   ```

5. システムを再起動
   ```
   npm run dev
   ```


================================================================================
■ 本番環境へのデプロイ（上級者向け）
================================================================================

Vercelなどのホスティングサービスにデプロイする場合：

1. Vercelアカウントを作成（https://vercel.com/）
2. GitHubリポジトリと連携
3. 環境変数 `DATABASE_URL` を設定
4. デプロイ実行

※ 本番環境ではSQLiteではなく、PostgreSQLなどの使用を推奨
